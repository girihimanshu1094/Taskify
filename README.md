Taskify - Simple Todo App

A simple and responsive Todo List application built using React.js and Tailwind CSS. This project allows users to manage daily tasks efficiently with a clean and beginner-friendly user interface.

Features
1. Add new tasks
2. Mark tasks as completed
3. Delete tasks
4. View total, completed, and pending tasks
5. Prevent empty task submissions
6. Responsive design for mobile and desktop
7. Modern UI with Tailwind CSS

Technologies Used
1. React.js
2. Tailwind CSS
3. JavaScript (ES6+)

Usage
1. Enter a task in the input field.
2. Click Add Task to create a new todo.
3. Click the checkbox to mark a task as completed.
4. Click the delete button to remove a task.
5. Track your task progress through the statistics section.
